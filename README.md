# 📊 Sales Performance Dashboard using Tableau

An interactive Tableau dashboard built using the **Sample Superstore** dataset to analyze sales performance, profitability, regional trends, and customer segments. This project provides actionable business insights through interactive visualizations and KPI tracking.

---

## 📷 Dashboard Preview

![Dashboard Preview](Images/dashboard.png)

---

## 🎯 Project Objective

The objective of this project is to analyze retail sales data and identify business trends related to sales, profit, customer segments, and regional performance. The dashboard enables users to explore the data interactively and make data-driven decisions.

---

## 📌 Key Performance Indicators (KPIs)

- 💰 Total Sales
- 💵 Total Profit
- 📦 Total Orders
- 📉 Average Discount

---

## 📈 Dashboard Visualizations

- Sales by Category
- Monthly Sales Trend
- Profit by Sub-Category
- Sales by State (Map)
- Sales vs Profit (Scatter Plot)
- Sales by Segment

---

## 🎛️ Interactive Features

## 💡 Key Business Insights

- Technology category generates the highest sales.
- Profit varies significantly across sub-categories.
- Sales performance differs across states.
- Consumer segment contributes the highest sales.
- Monthly sales show seasonal fluctuations.

## 🚀 How to Use

1. Clone this repository.
2. Open the `.twbx` file in Tableau Public/Desktop.
3. Explore the dashboard using the available filters.
